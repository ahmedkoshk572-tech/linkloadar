# LinkLoad

موقع عربي/إنجليزي لمعالجة روابط الفيديو العامة وعرض المعاينة والجودات ثم تنزيل الجودة المختارة عبر محرك yt-dlp داخل الخادم.

## التشغيل المحلي

يتطلب التشغيل الحقيقي Python و`yt-dlp` و`ffmpeg`. أسهل طريقة هي استخدام Docker:

```bash
docker build -t linkload .
docker run --rm -p 3000:3000 linkload
```

بعد التشغيل افتح `http://localhost:3000`. مسارات الخادم هي:

- `GET /downloader/health` للتحقق من جاهزية المحرك.
- `GET /downloader/preview?url=<PUBLIC_URL>` لإرجاع العنوان والصورة والجودات التي يجدها yt-dlp.
- `GET /downloader/download?url=<PUBLIC_URL>&format_id=<FORMAT_ID>` لبدء تنزيل الجودة المختارة.

## النشر

GitHub يحفظ الكود فقط. يجب نشر المشروع على بيئة تشغّل Docker أو تثبّت Python و`yt-dlp` و`ffmpeg`. لا تضع أي مفاتيح أو ملفات `.env` في المستودع. الخدمة مخصصة للروابط العامة والمحتوى الذي يملك المستخدم حق تنزيله، ولا تتجاوز المحتوى الخاص أو DRM أو صفحات تسجيل الدخول.

## حدود المصدر

قد ترفض بعض المنصات الطلبات الآلية أو تتطلب تسجيل دخول/ملفات cookies. في هذه الحالة يعرض الموقع رسالة الخطأ التي يرجعها المحرك بدل ادعاء نجاح التنزيل.
